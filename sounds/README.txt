CARPETA DE EFECTOS DE SONIDO PARA EL DIORAMA
=============================================

Coloca aquí archivos de sonido con los nombres de cada modelo.
Formatos aceptados: .mp3, .wav, .ogg

ARCHIVOS NECESARIOS (mismo nombre que el objeto):
- cree.mp3 (o .wav/.ogg)   → Se reproduce al enfocar el Creeper (tecla G)
- pick.mp3 (o .wav/.ogg)   → Se reproduce al enfocar el Pickaxe (tecla J)
- sword.mp3 (o .wav/.ogg)  → Se reproduce al enfocar la Sword (tecla K)
- buck.mp3 (o .wav/.ogg)   → Se reproduce al enfocar el Bucket (tecla L)

CONTROLES:
- G: Enfocar Creeper y reproducir creeper.wav
- J: Enfocar Pickaxe y reproducir pickaxe.wav
- K: Enfocar Sword y reproducir sword.wav
- L: Enfocar Bucket y reproducir bucket.wav
- Click Derecho: Cambiar modelo y reproducir su sonido

Si no se encuentran archivos de sonido, el programa generará
un sonido sintético genérico que se usará para todos los modelos.

SUGERENCIAS DE SONIDOS:
- Sonidos de Minecraft (hiss del creeper, swing de espada, etc.)
- Efectos característicos de cada objeto
- Sonidos cortos (0.1-1.0 segundos)

SITIOS PARA DESCARGAR SONIDOS GRATIS:
- freesound.org
- zapsplat.com
- sounds-resource.com (Minecraft sounds)

El volumen de los efectos está al 50% por defecto.
